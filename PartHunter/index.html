Search sources

Supercheap, Repco, Autobarn and eBay are searched directly, which is best effort because those sites can change or block automated requests. Added stores are checked as Shopify, WooCommerce or ordinary search pages. Open-web search finds product pages on any site and reads the price from each page. An Ollama key (free account at ollama.com/settings/keys) makes finding those pages more reliable than reading search engines. It is best effort, because search engines can block automated lookups and some sites hide their prices. A web search key adds more reliable Google Shopping results from sellers across Australia (Supercheap, Repco, Autobarn, eBay, Amazon and more, wherever Google lists them). Keys stay in this browser and are only sent to the PartHunter server and the search service. Settings are saved on this device.

How PartHunter works

Each search checks the live catalogues of your selected stores, plus the wider web through Google Shopping when you add a search key. It then separates exact code matches from possible cross-references. It does not search every seller or guarantee vehicle fitment. Prices, delivery and stock can change; confirm the part and checkout total with the retailer.
